# 🏠 Home-Decore App

A modern Home Decoration shopping application built with SwiftUI and Firebase.  
This app allows users to browse beautiful furniture and home decor products with a clean and responsive user interface.

---

# ✨ Features

- 🛋 Browse home decor products
- 🖼 Dynamic product images using SDWebImageSwiftUI
- 🔥 Firebase Firestore integration
- 📱 Modern SwiftUI interface
- 🧾 Product detail view
- 💰 Product pricing display
- 🎨 Custom reusable UI components
- ⚡ Async/Await Firebase fetching
- 🌙 Clean dark-themed design

---

# 🛠 Technologies Used

- SwiftUI
- Firebase Firestore
- SDWebImageSwiftUI
- Async/Await
- MVVM Architecture

# 🔥 Firebase Setup

- Create a Firebase project  
- Enable Firestore Database  
- Add GoogleService-Info.plist to the project  
- Install Firebase SDK
